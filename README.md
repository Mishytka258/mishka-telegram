# Mishka Telegram Mini App — first UI prototype

This is the first visual prototype for the personal Mishka app.

## Current scope
- Dark graphite theme with soft blue accents.
- Responsive mobile-first layout.
- Bottom navigation mockups: Home, Search, Palette, Statistics, Profile.
- Demo book cards only; they are placeholders, not a real catalog.
- No Telegram bot connection or backend yet.

## Publish
Upload the contents of this folder to the root of the `mishka-telegram` GitHub repository.
Then enable GitHub Pages from `main` / `/(root)`.

The Telegram Mini App will later use this HTTPS page as its frontend URL. A secure backend and Telegram bot configuration are still required.
